Comment connecter FL Companion à FL Studio
Cette app communique avec FL Studio via le protocole OSC (Open Sound Control). Un petit script Python tourne sur ton PC et fait le lien. Ton téléphone et ton PC doivent être sur le même réseau Wi-Fi.
1
Télécharger le script Python
FL Studio accepte des scripts Python pour contrôler n'importe quelle action. Ce script crée le pont entre cette app et FL Studio.
# Script : fl_companion_bridge.py # (Gratuit, open source — disponible sur GitHub)
2
Copier le script dans FL Studio
Place le dossier du script dans le répertoire MIDI Remote Scripts de FL Studio.
C:\Users\[Ton Nom]\Documents\ Image-Line\FL Studio\Settings\Hardware\ fl_companion_bridge\
3
Activer dans FL Studio
Menu FL Studio > Options > MIDI Settings > active 'fl_companion_bridge' dans la liste des contrôleurs.
FL Studio > Options > MIDI > Input : fl_companion_bridge > ✅ Enable
4
Même réseau Wi-Fi
Lance FL Studio ET ouvre cette app sur ton téléphone. Communication via OSC port 7000.
Protocole : OSC (Open Sound Control) Port : 7000 (UDP) IP locale : 127.0.0.1 (même PC)
5
Tester la connexion
Clique sur Play dans cette app. Si FL Studio réagit, c'est connecté ! 🎉
Problème ? Vérifie le pare-feu Windows : Autoriser l'accès au port UDP 7000 (Panneau de config > Pare-feu > Règles entrantes)
⚡ Alternative — Sans connexion en direct
Tu peux utiliser FL Companion sans rien installer sur ton PC :

• Tutoriels dans Arrangement Express et Checklist
• Générateur de structure visible en parallèle de FL Studio
• Checklist de mixage à cocher au fur et à mesure
• Visualisateur comme guide de référence visuelle
